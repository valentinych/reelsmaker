# RealsMaker

Веб-приложение для сборки вертикальных роликов Instagram Reels **1080×1920**. На вход — фото и видео с диска, вотермарка и подписи. На выход — MP4.

Интерфейс на русском. Фирменные цвета [trojmiasto.online](https://trojmiasto.online): фон `#56858C`, текст `#FFD8B5`. Шрифт подписей — **Jost Bold** (если файл шрифта лежит в `reels/fonts/`, иначе системный жирный шрифт).

## Что умеет

### Вкладка Reals

Ролик из фото и видео в заданном порядке, с вотермаркой на каждом кадре.

- Фото показывается заданное число секунд. Видео проигрывается как видео, со своим звуком, пока не подключена музыка с YouTube.
- Кадр вписывается в 9:16. Пустые поля заливаются фирменным цветом. Степень вписывания — 70–99% (по умолчанию 98%).
- У видео можно обрезать начало и конец.
- Вотермарка: позиция, размер (доля ширины кадра) и прозрачность. На Opening и титрах вотермарка всегда непрозрачная.
- Позиции вотермарки: справа/слева/по центру внизу, по центру слева и справа, строго по центру, по центру вверху.
- **Opening** и **Титры** включаются отдельно. Это кадры с фирменной заливкой и вотермаркой по центру экрана. У каждого своя длительность. Можно включить оба, один или ни одного. Opening идёт в начале ролика, титры — в конце.
- До **10 текстовых блоков**. У каждого: текст, старт на таймлайне всего ролика (включая Opening), длительность и угол: верх-лево, верх-право, низ-лево, низ-право.
- Блок выезжает от края к центру до 70% ширины кадра: разворот замедляется к концу, сворачивание начинается медленно и ускоряется.
- Если вотермарка стоит сверху или снизу и пересекается с текстом по горизонтали, подпись сдвигается, чтобы не закрывать знак. Вотермарка строго по центру текст не двигает.
- Музыка: ссылка YouTube и отрезок (начало и конец в секундах). Если музыка задана, она заменяет звуковую дорожку ролика.

### Вкладка «Статичный Reels»

Слайд-шоу только из вертикальных фото.

- Одинаковая длительность каждого кадра.
- Лёгкий Ken Burns, без текста и без вотермарки.
- Те же поля фирменного цвета и та же музыка с YouTube.

### Черновики

Состояние формы пишется в `localStorage` и периодически на сервер. Загруженные файлы живут во временном каталоге сессии около **6 часов**, после этого их нужно загрузить снова.

## Как устроено

Рендер не выполняется внутри HTTP-запроса. API кладёт задание в файловую очередь, отдельный воркер собирает MP4 через moviepy и ffmpeg.

```
браузер (React, /reel/)
        │
        ▼
FastAPI (/reel/api/)  ── пишет job в /tmp/realsmaker/jobs/
        │
        ▼
worker (python -m worker.run)  ── reels/ ── MP4
```

| Часть | Роль |
| --- | --- |
| `web/` | React + Vite. Форма, превью, опрос статуса job |
| `api/` | Загрузка файлов, черновики, создание и скачивание job |
| `worker/` | Очередь: забирает `pending`, рендерит, пишет статус |
| `reels/` | Кадр 1080×1920, вотермарка, тексты, музыка, Ken Burns |
| `app.py` | Ранний интерфейс на Streamlit. Текущий продукт — `web/` + `api/` |

Каталог `omage/` — отдельный эксперимент (озвучка и замена лиц). В репозиторий не входят исходные ролики, модели и голосовые сэмплы.

## Локальный запуск

Нужны Python 3.11+, Node.js 22+, **ffmpeg**. Для музыки с YouTube — **yt-dlp** в `PATH`.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

export TMPDIR=/tmp/realsmaker
mkdir -p "$TMPDIR"

python -m worker.run &
uvicorn api.main:app --reload --port 8770
```

Интерфейс в режиме разработки (прокси `/reel/api` → порт 8770):

```bash
cd web
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно с путём `/reel/`).

Проверка API: `GET http://127.0.0.1:8770/reel/api/health`  
Документация: `http://127.0.0.1:8770/reel/api/docs`

Собранный фронт (`npm run build` → `web/dist`) FastAPI отдаёт сам с `/reel/`, если каталог `web/dist` есть рядом с API.

## Docker

Образ собирает фронт и ставит ffmpeg и yt-dlp. Процесс в контейнере по умолчанию — только API (`uvicorn` на порту **8770**). Воркер нужно запустить отдельно и дать ему тот же том `/tmp/realsmaker`, иначе задания останутся в очереди.

```bash
docker build -t realsmaker .

docker run --rm -p 8770:8770 \
  -v realsmaker_tmp:/tmp/realsmaker \
  realsmaker

docker run --rm \
  -v realsmaker_tmp:/tmp/realsmaker \
  realsmaker python -m worker.run
```

В проде это два сервиса одного образа: `realsmaker` (API и SPA) и `realsmaker-worker` (`restart: unless-stopped`), общий volume `realsmaker_tmp`.

## API

Базовый префикс: `/reel/api`.

| Метод | Путь | Назначение |
| --- | --- | --- |
| `GET` | `/health` | `{"status":"ok"}` |
| `GET` | `/meta` | Подписи позиций вотермарки и углов текста |
| `POST` | `/media` | Загрузка фото, видео или вотермарки (`multipart`) |
| `GET` | `/media/file` | Отдача файла сессии для превью |
| `POST` | `/jobs` | Поставить рендер в очередь (`kind`: `watermark` или `static`) |
| `GET` | `/jobs/{id}` | Статус и прогресс |
| `GET` | `/jobs/{id}/download` | Готовый MP4 |
| `GET` / `POST` | `/drafts` | Список и сохранение черновика |
| `GET` | `/drafts/{name}` | Прочитать черновик |

`POST /jobs` принимает длительности фото, вписывание, позицию и размер вотермарки, флаги Opening и титров, до 10 текстовых блоков, ссылку YouTube и обрезку видео (`trim_start` / `trim_end`).

## Формат кадра

- Размер: **1080×1920**, 30 fps, H.264 + AAC.
- Фон полей и сплэш-кадров: `#56858C`.
- Подписи: шрифт `#FFD8B5`, плашка `#56858C`.
- Вотермарка на медиа масштабируется от ширины кадра. На Opening и титрах она крупнее и стоит по центру.

## Зависимости

Python: `requirements.txt` — FastAPI, uvicorn, moviepy 1.x, Pillow, numpy, requests, imageio-ffmpeg.

Фронт: React 19, TypeScript, Vite (`web/package.json`).
